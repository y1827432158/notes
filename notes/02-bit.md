# 二、位运算

## 2.1 取二进制第 i 位 `n >> i & 1`

- 含义：把 `n` 右移 `i` 位，最低位就是原来的第 `i` 位（`i` 从 **0** 开始）
- 优先级：`>>` 高于 `&`，所以等价于 `(n >> i) & 1`，可以省括号
- 结果只有 0 / 1，直接当条件用

```cpp
n >> i & 1          // 第 i 位是 0 还是 1

int cnt = 0;
for (int i = 0; i < 32; i++)
    if (n >> i & 1) cnt++;      // 统计二进制中 1 的个数（AcWing 801）
```

**负数**：`int` 存的是**补码**，位运算按补码做，所以 `-2` 的 32 位里前面 31 个 1 都会被数到（结果 31）。

**相关写法**

| 写法 | 作用 |
| --- | --- |
| `n & 1` | 取最低位，等价于 `n % 2`（判奇偶） |
| `n >> i & 1` | 取第 `i` 位 |
| `n & -n` | lowbit：最低位的 1 及其后面的 0 |
| `n -= n & -n` | 消掉最低位的 1，循环几次就有几个 1 |
| `__builtin_popcount(n)` | 1 的个数，一行搞定 |

**易错点**

- 位数从 0 开始，第 32 位不存在（`int` 只有 0~31）
- `while (n) { cnt += n & 1; n >>= 1; }` 对**负数死循环**——算术右移高位补 1，永远不为 0。要么限制 32 次，要么用 `unsigned`

## 2.2 lowbit `n & -n`

- 作用：取出**最低位的 1 及其后面的 0**，返回那个数（`12 = 1100₂ → 4`）
- 原理：`-n` 在补码里等于 `~n + 1`，高位与 `n` 全相反、最低位 1 那里两边都是 1 → 与完只剩那一位

```text
 12 = 0000 1100
-12 = 1111 0100     （补码）
  & = 0000 0100 = 4
```

**核心用法：消掉最低位的 1**，循环次数 = 1 的个数

```cpp
int cnt = 0;
while (n) { n -= n & -n; cnt++; }    // 有几个 1 就转几圈
```

**树状数组的命根子**：`i += i & -i` 往上、`i -= i & -i` 往下，O(log n) 就是从这来的

```cpp
void add(int i, int v) { for (; i <= n; i += i & -i) tr[i] += v; }        // 更新
int  sum(int i) { int s = 0; for (; i; i -= i & -i) s += tr[i]; return s; }  // 前缀和
```

| 顺手用途 | 写法 |
| --- | --- |
| 判断 2 的幂 | `(n & -n) == n` |
| 最低位 1 的下标 | `__builtin_ctz(n)` |
| 抹掉最低位 1（等价写法） | `n &= n - 1` |

**易错点**

- `n & -n == n` **是错的**：`==` 优先级高于 `&`，会被算成 `n & (-n == n)`。判 2 的幂必须写 `(n & -n) == n`
- 只数 1 的个数时用 `__builtin_popcount(n)` 更快（一条指令），lowbit 的价值在树状数组和「要逐个拿到每个 1」
- 始终按**补码**理解，别在心里拆成「符号位 + 数值」
