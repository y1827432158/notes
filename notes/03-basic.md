# 三、基础算法模板

## 3.1 快速排序（手写）

- 分治：选基准 `x`，把区间分成「≤ x」和「≥ x」两半，再分别递归
- 平均 O(n log n)，最坏 O(n²)；**原地排序、不稳定**
- 全程用**闭区间** `[l, r]`

```cpp
void quick_sort(int q[], int l, int r) {
    if (l >= r) return;                  // 0 或 1 个元素，不用排
    int x = q[l], i = l - 1, j = r + 1;  // i、j 先站到区间外

    while (i < j) {
        do i++; while (q[i] < x);        // 从左找第一个 >= x 的
        do j--; while (q[j] > x);        // 从右找第一个 <= x 的
        if (i < j) swap(q[i], q[j]);     // 两边都停下才交换
    }
    quick_sort(q, l, j);                 // 左半 [l, j]
    quick_sort(q, j + 1, r);             // 右半 [j+1, r]
}
```

**为什么这么写**

| 写法 | 原因 |
| --- | --- |
| `i = l - 1, j = r + 1` 配 `do i++` | 第一轮正好指向 `l` 和 `r`，省掉特判 |
| 用 `do-while` 而不是 `while` | 保证至少动一格；`while` 会在 `q[i] == x` 时卡住不动，死循环 |
| 比较写**严格** `<` / `>` | 等于基准的元素也停下参与交换 → 等于 `x` 的值被均匀分到两侧，**这是避免最坏 O(n²) 的关键** |
| `int x = q[l]` 存成变量 | 直接拿 `q[l]` 比较的话，交换之后基准就漂了 |

**递归边界（最容易写错的地方）**

- 基准取**左端** `q[l]` → 只能用 `j` 分：`[l, j]` 和 `[j+1, r]`
- 写成 `[l, i-1]` 和 `[i, r]` 会**无限递归**：以 `[1, 2]` 为例，循环结束时 `i == l == 0`，右半边 `[i, r]` 还是原区间，永远缩不小
- 口诀：基准取**左端** `q[l]` 就用 `j` 分，取**右端** `q[r]` 就用 `i` 分；取中间 `q[(l+r)/2]` 两者皆可
- `if (l >= r) return;` 不能省 —— 单元素区间 `[k, k]` 用 `j` 分会退化成 `[k, k]` 加一个空区间，自己递归自己

**易错点**

- 分界变量**不对称**：用了 `j` 就一路 `j`，别一半 `i` 一半 `j`
- 循环条件 `while (i < j)` 不能写成 `<=`
- 快排**不稳定**（相等元素的相对次序会变），要保序用归并 / `stable_sort`
- 比赛里直接用 `sort`（内省排序，最坏也是 O(n log n)）；手写快排是为了理解分治、应付手写题
- **调用传的是闭区间**：`quick_sort(q, 0, n - 1)`。传 `n` 会多算一个越界元素，不报错但答案错
- 数组怎么开见 3.3

## 3.2 快速选择（求第 k 小数）

- 用途：**无序**数组求第 `k` 小，平均 **O(n)** —— 比「先整体排序再取」的 O(n log n) 更快
- 做法：分区之后**只递归目标所在的那一边**，另一半整个丢掉
- `k` 从 **1** 开始编号；第 k 大 = 第 `n - k + 1` 小

```cpp
int quick_select(int q[], int l, int r, int k) {
    if (l == r) return q[l];
    int x = q[l], i = l - 1, j = r + 1;

    while (i < j) {                               // 分区部分和快排一模一样
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    int sl = j - l + 1;                           // 左半边的元素个数
    if (k <= sl) return quick_select(q, l, j, k);         // 在左边：仍是第 k 小
    return quick_select(q, j + 1, r, k - sl);             // 在右边：变成第 k-sl 小
}
```

**为什么是 O(n)**：每层只处理一半，`n + n/2 + n/4 + … = 2n`（快排是每层处理全部，所以多一个 log）

**和快排的区别**

| | 快速排序 | 快速选择 |
| --- | --- | --- |
| 递归 | 左右都递归 | **只递归一边** |
| 时间 | O(n log n) | 平均 O(n)，最坏 O(n²) |
| 产出 | 整个数组有序 | 只求出第 k 个 |

**STL 版本**

```cpp
nth_element(v.begin(), v.begin() + k, v.end());   // 第 k 小（0 基）就位
```

- 结束后下标 `k` 上就是第 k 小，左边都不大于它、右边都不小于它，但**两边不保证有序**
- 求前 k 小：`nth_element` 之后取 `[0, k)`，需要有序再 `sort` 这 k 个
- 实现是内省选择，平均和最坏都是 O(n)，比自己手写稳

**易错点**

- 分区照抄快排，所以分界点的坑完全一样：基准取左端 `q[l]` 就只能用 `j` 分
- 调用同样是**闭区间**：`quick_select(q, 0, n - 1, k)`
- `k` 是 **1 基**，而 `nth_element` 是 **0 基**，两边换算别差一位
- 最坏 O(n²)：输入有序 + 基准取 `q[l]` 时每轮只缩 1 个，换 `q[(l+r)/2]` 更稳
- **会打乱原数组**（原地分区），后面还要用原顺序就别用
- 数据是**流式**的、或不能改原数组 → 用小顶堆 O(n log k)
- AcWing 786「第 k 个数」就是这个模板

## 3.3 大数组怎么开：`const` 与全局

**为什么 `int N = 100000; int q[N];` 编译不过**

- 数组长度要的是**编译期常量**，而 `int N` 定义的是**变量**
- `N = 5;` 是合法语句；全局非 `const` 变量还是**外部链接**（别的 `.cpp` 写 `extern int N;` 就能改）—— 编译器没法假设它不变
- 所以标准规定数组维度必须是**常量表达式**。编译器在优化阶段确实会把 `N` 替换成 `100000`，但那是**优化，不是语义**，语法检查这关照样拦

```cpp
int N = 100000;          // 变量：值随时能改
int q[N];                // ✗ 编译期算不出要分配多少字节

const int N = 100000;    // 常量：编译期定死
int q[N];                // ✓
```

| 写法 | 能否当数组长度 |
| --- | --- |
| `int N = 1e5;` | ✗ 是变量 |
| `const int N = 1e5;` | ✓ C++ 可以 |
| `constexpr int N = 1e5;` | ✓ C++11，语义最明确 |
| `#define N 100010` / `enum { N = 100010 };` | ✓ |
| 字面量 `int q[100000]` | ✓ |

**C 和 C++ 不一样**：C 里的 `const` 只是「只读变量」，`const int N = 1e5; int q[N];` 在 C 里**编译不过**，得用 `#define` 或 `enum`。别把 C 的规则套过来。

**为什么必须放全局**

- 全局数组在**静态存储区**，开多大都不占栈，还自动清零
- 写在函数里：100000 个 `int` = 400KB，而默认栈只有 1MB，n 再大点就**爆栈**——评测机报 RE / 段错误，很难查到原因

**别依赖 GCC 的 VLA 扩展**

```cpp
int main() {
    int n; cin >> n;
    int q[n];       // GCC 扩展放过去了，但非标准 + 栈上分配
}
```

- 只在**函数内**有效；写在全局时连 GCC 都不放行（全局变量大小必须编译期定死），所以那种写法在全局是**硬编译错误**
- MSVC 直接报错，Clang 只当扩展容忍

**模板**

```cpp
const int N = 1e5 + 10;   // 多开 10 个，防差一（闭区间传参、前缀和从 1 开始……）
int q[N];                 // 全局
```
